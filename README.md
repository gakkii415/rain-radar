# 雨雲レーダー

場所を検索して、気象庁の高解像度降水ナウキャストを現在から60分後まで5分刻みで確認できるWebアプリです。

## 主な機能

- 地名・住所を入力して地図を移動
- 現在地への移動
- 実況〜60分後の時刻スライダー
- 雨雲の動きの自動再生
- 最後に選んだ場所と検索結果を端末内に保存

## データ

- 雨雲：気象庁「高解像度降水ナウキャスト」
- 地図：国土地理院「地理院タイル（淡色地図）」
- 場所検索：OpenStreetMap Nominatim

場所検索は検索ボタンを押したときだけ行い、同一検索の結果を24時間端末内へ保存します。Nominatimの公開サービスを利用するため、大規模利用時は独自の検索基盤または商用サービスへ切り替えてください。

## 開発

追加のビルドは不要です。`dist/index.html` を静的サーバーで配信してください。

```bash
npm test
```
